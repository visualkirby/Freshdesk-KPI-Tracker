# Freshdesk KPI Tracker

**Helpdesk Analytics | Support Operations | Freshdesk API**

Daily performance tracking system for a customer support team: ticket volume per agent pulled from Freshdesk's API, checked against a configurable target, with automated alerts and an AI-generated daily insight summary. Built as a working rebuild of a real Upwork contract's architecture, on a helpdesk platform whose API isn't blocked by client-side SSO.

---

# Project Overview

A support team needs daily visibility into ticket load per agent, an automatic flag when someone falls below target, and a supervisor summary, without anyone manually pulling reports. This project builds that system end to end against Freshdesk: ticket data in, performance calculated against a configurable threshold, alerts and a trend dashboard out.

The design mirrors a real Benchline Analytics engagement (helpdesk ticket data to a KPI list to automated notifications to a Power BI dashboard to a daily AI-generated pattern summary), rebuilt here against Freshdesk's API after the original engagement's Zendesk connection was blocked by the client's SSO configuration.
